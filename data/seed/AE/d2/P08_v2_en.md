# Raising daily transfer limits - Version 2

Effective date: 2026-09-01

## 1. Purpose
The purpose of this procedure is to outline the standardized process for customers to increase their daily fund transfer limits, ensuring security and operational consistency across all banking channels. This version supersedes version 1.

## 2. Scope
This procedure applies to all retail banking customers requesting adjustments to their daily transaction limits via the mobile application or through physical branch visits.

## 3. Steps
1. **Standard Limit Access:** Customers may utilize the default daily transfer limit provided by the bank.
2. **Digital Limit Increase:** To increase the limit via the mobile application, the customer must complete a verification process using UAE PASS.
3. **Manual Limit Increase:** For requests exceeding the maximum digital threshold, the customer must visit a physical branch to submit a formal request.
4. **Verification:** Branch staff must ensure the request is signed by the account holder before processing.

## 4. Fees and timelines
* **Digital Increase:** Immediate upon successful UAE PASS verification.
* **Branch Request:** Requests submitted via a signed form in the branch will become effective on the following business day.

## 5. Required documents
* **For App-based increases:** Valid UAE PASS credentials for identity verification.
* **For Branch-based increases:** A signed written request form.

## 6. Notes
* **Default Limit:** The default limit is 40,000 AED via the mobile application.
* **Maximum App Limit:** The maximum limit achievable through the mobile application is 120,000 AED, contingent upon successful verification via UAE PASS.
* **Exceeding Limits:** Any amount exceeding the 120,000 AED threshold requires a signed request submitted in-branch and will take effect on the next business day.
